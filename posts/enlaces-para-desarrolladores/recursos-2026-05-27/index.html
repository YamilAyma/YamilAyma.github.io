Unos 4 recursos sobre frontend y UI.

Ninja Backgrounds: Colección de fondos dinámicos y patrones visuales para proyectos Bootstrap. Link: https://ui.bootstrap.ninja/ninja-backgrounds/

BeerCSS: Framework de diseño basado en Material Design 3 con una sintaxis extremadamente simple. Link: https://www.beercss.com/

FlyonUI: Librería de componentes moderna construida sobre Tailwind CSS y JS nativo. Link: https://flyonui.com/

Mielo UI: Conjunto de componentes ligeros con una estética minimalista y moderna. Link: https://mielo-ui.github.io/
